 CineVault – Online Movie Information System

CineVault is a movie information website built using HTML, CSS, JavaScript, and JSON.

Features
- Browse movies and TV shows
- Search for movies by title
- Filter movies by genre
- View movie details and ratings
- Add movies to a personal watchlist

Technologies Used
- HTML
- CSS
- JavaScript
- JSON
- XAMPP

How to Run
1. Install XAMPP.
2. Place the project folder inside `htdocs`.
3. Start Apache.
4. Open the project through `http://localhost/` in your browser.
